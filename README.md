# Vortex — Visual Development Platform Landing Page

A modern, high-conversion dark-mode landing page inspired by Webflow, Linear, and Framer. Built with Tailwind CSS (via CDN) and vanilla JavaScript.

![Preview](https://images.unsplash.com/photo-1618005182384-a83a8bd57fbe?auto=format&fit=crop&w=1200&q=80)

## ✨ Features

- **Webflow / Framer Aesthetic**: Deep obsidian backdrop, subtle glow gradients, and glassmorphism.
- **Interactive Visual Canvas Mockup**: Simulated multi-device canvas editor with layer tree navigation and CSS box-model style inspector.
- **Bento Grid Showcase**: Asymmetric feature cards highlighting code export, sub-10ms global CDN latency, design tokens, and live multiplayer presence.
- **100% Tailwind Play CDN**: Zero build step or npm dependencies required—open and run directly in any browser.
- **Responsive & Accessible**: Optimized for desktop, tablet, and mobile displays.

## 🚀 Getting Started

Simply open `index.html` in your web browser:

```bash
# Double-click index.html or open via terminal
start index.html
```

## 🛠 Tech Stack

- **Styling**: [Tailwind CSS CDN](https://tailwindcss.com/)
- **Typography**: [Plus Jakarta Sans](https://fonts.google.com/specimen/Plus+Jakarta+Sans) & [JetBrains Mono](https://fonts.google.com/specimen/JetBrains+Mono)
- **Icons**: Inline Heroicons SVGs
